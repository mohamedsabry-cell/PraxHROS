# Praxion HROS

**13-module Human Resources Operating System.**
Built by PraxionHR — Project Director & Product Owner: Sabry M.

This repository is the working backlog + docs + artifacts for the Praxion HROS build.

## Start here

- **`CLAUDE.md`** — project primer (load first if you're using Claude Code).
- **`BRDs/`** — 13 signed Business Requirements Documents (one per module).
- **`Roadmap/`** — Phase 1 tracker + Jira PRX import package (README + 2-pass CSVs).
- **`Meeting-Docs-Apr22/`** — Discovery phase close-out (5 decks + PDFs).
- **`Modules/M1–M13/`** — per-module deep-dive (Architecture, BRD, Design, Dev, Discovery, Roadmap, Security, Specs, User-Stories).

## Status (as of 2026-04-21)

Discovery phase complete. Phase 1 (M1 Core HRIS + M10 System Administration) is in mobilisation. Build sprints 0–22 are mapped; 9 Epics are live in Jira `PRX`, with 219 Tasks + 575 Subtasks staged for CSV import.

## Rules for contributors (and Claude Code)

- **Version, don't overwrite.** New revisions get a bumped `-vN` suffix.
- **Dual-location.** Canonical docs live in both `/TopFolder/` and `/Modules/M{n}/` — keep both in sync.
- **No client PII.** `Business Docs/` folders are gitignored; they contain real client/HR data that never enters this repo.

See `CLAUDE.md` for the full primer.

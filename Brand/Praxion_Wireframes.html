Persistent elements

  • Sidebar (240px): module nav, workspace switcher, collapse to icon-rail
  • Top bar (56px): workspace, ⌘K command bar, notifications, settings, profile
  • Main canvas: 12-col grid, page header (title + actions), tab strip when needed, content

Role visibility

  • Admin Full access. Sees Admin module, billing, integrations, audit log.
  • HR All HR modules, no billing/integrations. Cannot impersonate.
  • Manager Team-scoped views: direct reports only on People, Time, Leave, Perf, Pay (read).
  • Employee Self-service only: own profile, time, leave, pay, docs, perf.

01 — Logo System

Three directions, one system.

Each direction shares a common construction grid (6×6), the same wordmark, and the same negative space rhythm. None use human icons or HR clichés.

01 · Safe / Corporate

A symmetrical node mark — four endpoints converging on a Signal Blue nucleus. Reads as a system diagram. Enterprise sales, RFPs, compliance.

02 · Bold / Modern

A kinetic ascent — three accelerating segments terminating in a charged node. The 'ION' suffix carries the accent color. Marketing, launches, hero.

03 · Futuristic / System

An isometric lattice of six nodes around a core — a workforce graph in miniature. Pairs with monoline wordmark. AI surfaces, platform pages.

Dark mode lockups

Usage rules

Clear space

Always preserve clear space equal to the height of the 'P' on every side of the lockup. The mark may stand alone in dense UI; the wordmark may stand alone in body text.

Minimum size

Mark: 24 px digital / 8 mm print. Lockup: 96 px digital / 22 mm print. Never re-color, skew, outline, drop-shadow, or set on a busy photographic background.

02 — Color System

A restrained palette built for instruments, not infographics.

60% deep base · 30% neutral surfaces · 10% charged accent. Signal Blue is reserved for interactive elements so color always carries meaning.

Primary

Navy and Indigo carry the brand. Use as page backgrounds, hero sections, and product chrome. Never use as body text on white.

Neutral

Cloud White and Mist (#E6EAF2) hold dense data. Graphite is the default body text color on light surfaces.

Accent

Signal Blue = interaction. Ion Teal = automation, AI, success. Subtle Violet (#7C5CFF) is permitted only for AI-generated content.

03 — Typography

Inter. With JetBrains Mono for data.

Inter is the primary UI and marketing typeface — neutral, technically capable, and globally legible. JetBrains Mono is reserved for IDs, numerical tables, and API surfaces.

04 — Product UI Direction

Mission control, not a homepage.

Praxion's surface is a calm, dense, dark-canvas command center. Cards are modular operational units. Signal Blue marks action; Ion Teal marks automation. Motion is functional, never decorative (150–250 ms ease-out).

05 — Iconography

Geometric. 1.5 px. On a 24-grid.

A single line system, rounded terminals, never decorative. People are represented as nodes — never silhouettes. Module families share a rounded-square base so the product line reads as one system.

06 — Visual Elements

Pattern: the workforce graph.

A single system motif — a sparse lattice of nodes and connectors — appears across hero backgrounds, loaders, and slide dividers. It is always low-opacity, always behind content, and always derived from the logo grid.

RTL Implementation Rules

CSS Module Strategy
Use logical properties (margin-inline-start instead of margin-left). Set dir="rtl" on <html>. Sidebar flips to the right. Icons that imply direction (arrows, chevrons) must be mirrored. Numbers and dates remain LTR even in RTL context.
Bilingual Fields
Every user-facing label has name_en and name_ar fields. Form inputs show both language fields side by side. Date pickers support Gregorian and Hijri calendars. Currency displays as EGP with Arabic numeral option. Working week defaults to Sun–Thu for Egypt locale.
<\!-- ═══════════ 22 — ACCESSIBILITY ═══════════ -->
22 — Guidelines

Accessibility

WCAG 2.1 Level AA minimum. Every interactive element must be keyboard-navigable with visible focus indicators.

Color Contrast
Navy on White = 16.7:1 (AAA). Muted on White = 4.8:1 (AA). Signal on White = 4.5:1 (AA). Never rely on color alone for status — always pair with text labels or icons.
Keyboard Navigation
Tab through all interactive elements. Enter/Space to activate buttons. Escape to close modals and dropdowns. Arrow keys for radio groups, tabs, and menus. Focus trap in modals. Skip-to-content link on every page.
Screen Readers
ARIA labels on all icon-only buttons. role="alert" for toasts. aria-live="polite" for dynamic updates. Semantic heading hierarchy (h1→h6). Status badges announced as text, not color.

CSS Modules Guide

How to use this design system with React + CSS Modules. All tokens defined as CSS custom properties in a global tokens.css file.

/* tokens.css — import globally in _app.tsx */ :root { /* Copy all CSS custom properties from this design system */ --navy: #0B1437; --signal: #2F6BFF; --ion: #19D3C5; /* ... all tokens ... */ } /* Button.module.css */ .root { display: inline-flex; align-items: center; font-family: var(--font-head); font-weight: var(--weight-semi); border-radius: var(--radius-md); transition: all var(--duration-normal) var(--ease-default); } .primary { background: var(--signal); color: var(--white); } .primary:hover { background: #2458D9; } .sm { padding: 6px 12px; font-size: var(--text-xs); } .md { padding: 10px 18px; font-size: var(--text-sm); } .lg { padding: 14px 24px; font-size: var(--text-base); }
// Button.tsx import styles from './Button.module.css'; import clsx from 'clsx'; type ButtonProps = { variant?: 'primary' | 'secondary' | 'ghost' | 'danger' | 'ion'; size?: 'sm' | 'md' | 'lg'; loading?: boolean; children: React.ReactNode; }; export function Button({ variant = 'primary', size = 'md', loading, children, ...props }: ButtonProps) { return ( <button className={clsx(styles.root, styles[variant], styles[size], loading && styles.loading)} disabled={loading} {...props} > {children} </button> ); }

Z-Index Scale

Structured z-index layers to prevent stacking conflicts. Always use tokens, never arbitrary values.

--z-dropdown · 100Select menus, autocomplete
--z-sticky · 200Sticky table headers, topbar
--z-overlay · 300Modal backdrop, sidebar overlay
--z-modal · 400Modal dialog
--z-popover · 500Popovers, date pickers
--z-toast · 600Toast notifications
--z-tooltip · 700Tooltips (always on top)
